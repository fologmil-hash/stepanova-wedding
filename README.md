# Сайт Марии Степановой — организатор свадеб и торжеств

Статичный одностраничный сайт для GitHub Pages: без сборки, без зависимостей.

## Файлы
- `index.html` — вся страница; тексты-заглушки помечены `[Текст-заглушка]`, `[Отзыв-заглушка]`, `[цена]`
- `config.js` — имя, телефон, WhatsApp, Telegram, Instagram, почта, цифры «обо мне»
- `styles.css` — оформление; палитра в начале файла (`:root`)
- `script.js` — меню, анимации, слайдер отзывов, форма
- `assets/img/` — сюда класть фото

## Как заменить фото
Блок `<div class="ph">…</div>` меняется на `<img src="assets/img/имя.jpg" alt="описание" loading="lazy">`.
Фон главного экрана: раскомментировать строку `hero.jpg` или `hero.mp4` в секции HERO.

## Форма заявки
GitHub Pages не принимает формы на сервере, поэтому заявка открывается готовым сообщением в WhatsApp (или копируется для Telegram).

## Публикация
Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.

## Свой домен
1. Создать в корне файл `CNAME` с одной строкой: `stepanova-wedding.ru`
2. У регистратора домена добавить A-записи на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` и CNAME `www` → `<логин>.github.io`
3. В Settings → Pages указать домен и включить `Enforce HTTPS`.
